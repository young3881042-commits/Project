# Orbit 웹·앱 출시 UI/UX 점검 기록

마지막 갱신: 2026-09-06

이 문서는 같은 화면을 매번 처음부터 다시 분석하지 않기 위한 기준서다. 다음 작업자는 먼저 이 문서와 `git diff`를 읽고 이미 끝난 항목은 재작업하지 않는다.

## 제품 방향

- 목표: 일정, 메모, 가계부를 매일 부담 없이 기록하는 생활 앱
- 유지할 큰 틀: 홈 월간 캘린더, 기능별 화면, 여행을 포함한 하단 5개 탭, 로컬 저장 중심 구조
- 우선순위: 빠른 입력, 명확한 저장 상태, 모바일 한 손 사용, 데이터 신뢰
- 비목표: 브랜드 컬러 교체와 기존 로컬 데이터 삭제

## 반영한 변경

### 2026-09-06 기존 여행 초안 재구성

- 사용자 요청에 따라 여행 탭을 추가하고 기존 플래너 입력 화면을 고쳤다. 장소 검색·추천·중복 안내와 많은 상세 입력을 한꺼번에 노출하던 구조를 여행 기본 정보 + 접힌 취향으로 줄였다.
- `계획 만들기/내 여행`을 분리하고 초록색 여행 안내, 44px 이상 조작 영역, 날짜 선택 레일과 시간순 일정으로 정리했다. 비용·이동 상세와 여행 팁·출처는 접어 볼 수 있다.
- 입력 초안과 미리보기를 보존하고 저장을 눌러야 여행 백업 대상에 포함한다. 생성 중 탭 이동, 취소, 연결 재확인, 저장 실패, 빈 목록, 오래된 체크리스트를 각각 처리한다.
- 연결 안내는 접힌 패널 한 곳에서 제공한다. 별도 API 키 입력 없이 Termux 일회 코드로 연결하며 다른 생활 기록은 전송하지 않는다. 실제 Codex 생성은 확인했고 UI는 SSR 렌더/구조 검증을 수행했다. 실제 Android 터치·회전·업데이트 설치 검증은 아직 별도다.
- 위 점수표는 이전 평가 기록이며 이번 기능 추가로 점수를 자동 상향하지 않는다.

### 2026-09-05 홈·가계부 가독성과 거래 검색

- 홈의 두 활동 지표를 2열로 맞추고 숫자를 키웠으며 긴 금액이 잘리지 않게 줄바꿈한다. 브리핑 전환 버튼은 44px 이상으로 키우고 설명 글자의 가독성을 보강했다.
- 월간 지갑은 청록색 금액 영역과 월 예산/지출 비교를 분리한다. 예산 미설정 시 실제 월 지출을 먼저 보여주고 예산 초과는 제목·사용률·색으로 함께 구분한다.
- 가계부 내부 메뉴에 아이콘을 추가하고 하단 탭 글씨·선택 대비를 개선했다. 거래 카드는 날짜·메모를 줄바꿈하고 금액과 수정/삭제 버튼을 별도 행에 표시한다.
- 현재 목록 범위 안에서 사용처·메모·분류·날짜·금액을 검색하고 전체/지출/수입을 선택할 수 있다. 결과 건수, 검색어 지우기, 빈 결과의 초기화를 제공하며 처음 8건/추가 20건 정책을 유지한다.
- 월·카테고리 또는 선택 날짜가 바뀌면 검색과 표시 개수를 초기화한다. 기존 거래 수정·삭제 후 되돌리기와 로컬 저장 경계는 유지한다.
- 시각 보정은 `lifehub-polish.css`, 목록 상태는 `FinanceLedger.jsx`, 검색 계산은 `financeLedgerSearch.js`에 분리했다. 실제 화면 너비별 시각 확인과 기기 키보드·업데이트 설치는 별도 확인이 필요하다.

### IndexedDB 호환 저장과 일상 입력 복구

- 기존 로컬 기록을 유지하면서 생활 데이터만 IndexedDB에 이중 보관하고, 시작 시 캐시와 데이터베이스를 복구·이관
- 가계부 거래 수정과 삭제 후 7초 되돌리기, 사용자가 직접 설정한 월 예산 진행률 추가
- 홈에서 일정·메모·지출 입력으로 바로 이동하고 월 달력의 날짜별 메모 표시·목록·편집 이동 연결
- 설정에서 저장 방식·대략적인 사용량·마지막 백업·14일 백업 권장을 표시하고 Orbit 명칭으로 통일
- 로그인·서버 전송·클라우드 동기화는 추가하지 않아 기존 기기 내부 저장 경계를 유지
### 미완료 일정과 메모 폴더 정보 구조

- 완료하지 않은 지난 날짜·오늘 시간이 지난 일정을 `미완료`로 구분하고 1분 자동 갱신, 전용 필터, 붉은 상태 칩을 제공
- 홈 월 달력과 아침 브리핑도 `예정·미완료·완료` 용어를 공유하고 브리핑의 `미완료 일정`을 해당 필터로 직접 연결
- 메모는 820px 이상에서 좌측 폴더 사이드바, 작은 화면에서 포커스 트랩·Escape·배경 닫기를 지원하는 폴더 서랍을 사용
- 폴더 생성·이름 변경·삭제·메모 이동을 하나의 사이드바와 카드 작업 메뉴에 연결하고, 폴더 삭제 시 안의 메모는 `개인`으로 이동해 보존
- 폴더 중복 ID·순환 참조·예약 ID·없어진 예전 폴더를 읽기 시 안전하게 복구

### 일반 텍스트 메모 작성 경험

- Markdown 툴바, `/` 명령, 작성·미리보기 전환과 GFM 렌더러를 제거하고 본문 입력 하나만 남김
- `Ctrl/Command+Enter` 저장, 접힌 폴더·제목·태그, 검색·필터와 카드 작업 메뉴는 유지
- 저장 카드와 이전 rich 메모 읽기 화면도 HTML을 해석하지 않는 일반 텍스트로 표시
- 이전 rich 메모는 원본을 덮지 않는 텍스트 사본으로만 편집해 기존 데이터를 보존
- 카드마다 반복되던 편집·고정·삭제 아이콘을 작업 메뉴 하나로 통합하고, 900px 이상에서 작성란 옆에 남던 빈 열을 제거
- 실제 메모에 존재하는 태그만 필터에 표시하고 검색 결과 수와 필터 초기화를 명시
- ID가 없는 이전 메모는 첫 읽기 때 안정된 ID와 시각을 저장해 이후 수정·삭제 대상이 바뀌지 않게 보강
- 현행 홈 규칙만 `lifehub-home.css`로 분리하고 58KB 규모의 보관용 AI 스타일을 production 진입점에서 제외

### 정기 결제와 예정 일정 날짜·시간

- 월간 지갑 아래 정기 결제 요약에서 이번 달 예정액, 실제 기록액, 다음 결제와 기록 건수를 분리
- 이름·금액·1~31일/말일·카테고리·시작/종료월·자동 반영·사용 상태를 한 관리 sheet에서 추가·수정
- 29~31일이 없는 달의 말일 보정, 규칙·월 고정 ID, 처리월 이력으로 중복과 삭제 후 자동 재생성을 방지
- 카드 알림 가져오기 사용 중에는 자동 반영을 기본 해제하고 동시 사용 경고를 제공
- 일정 `예정` 필터의 타임라인 레일에 날짜와 시간을 함께 표시하고 본문 날짜 중복을 제거

### 가계부 일회성 파일 공유

- 월간·전체·직접 선택 기간의 거래 수와 수입·지출 합계를 확인한 뒤 Orbit용 JSON 또는 보기용 CSV를 생성
- 메모는 기본 제외하며 카드 알림 ID, owner, native queue와 내부 origin 원본은 파일에 넣지 않음
- 받은 JSON의 새 거래·이미 있는 거래·수입·지출을 먼저 보여주고 새 거래만 추가해 기존 장부를 덮거나 지우지 않음
- 같은 파일을 다시 받거나 받은 거래를 재공유해도 안정된 공유 ID로 중복 생성을 막음
- Android는 시스템 공유 창만 열어 Bluetooth·Quick Share·메신저를 선택하게 하고, 별도 Bluetooth·광역 저장소 권한은 요구하지 않음
- private cache의 tokenized 파일을 non-exported Provider로 제공하고 선택한 수신 앱에 임시 읽기 권한만 부여하며 24시간이 지난 관리 파일은 정리
- 최근 거래는 8건을 우선 표시하고 20건 단위로 펼쳐 긴 장부의 첫 화면 밀도를 낮춤

### 운동·식단 제품 범위 제외

- 하단 메뉴를 `홈·일정·메모·가계부` 4개 탭으로 정리
- `/workout`, `/diet` 직접 주소를 `/app`으로 이동하고 두 화면의 production import와 전용 CSS를 제거
- 홈 월간 캘린더·활동 요약과 아침·저녁 브리핑에서 운동·식단 기록 및 이동 버튼을 제거
- 운동이 만들었던 레거시 연결 일정은 저장소에서 삭제하지 않고 현재 화면·알림에서만 제외
- 운동·식단 호환 필드는 보존하되 백업 화면에는 현재 제공하는 일정·메모·가계부·정기 결제·여행만 표시
- 설치된 PWA가 오늘 날짜 상세의 일정·메모 버튼과 남은 예산 기준 월간 지갑을 즉시 받도록 서비스 워커를 `orbit-web-v42`로 갱신

### 홈 활동 요약 기간

- 별도 `빠른 기록` 카드는 제거
- 기존 활동 요약 카드에 `주·월·연·전체` 기간 선택 추가
- 완료 일정과 지출 합계를 선택 기간에 맞춰 계산
- 월·연 통계는 주간 합산이 아니라 원본 기록 날짜를 기준으로 계산

### 하단 내비게이션

- 홈·일정·메모·가계부 4개 탭만 유지
- 아이콘을 22px로 키우고 라벨 행간을 고정

### 설치·백업 진입점 복구

- 구현되어 있었지만 라우터에서 홈으로 되돌려 보내던 `/more` 화면을 정상 연결
- 모든 주요 화면 상단에 44px 설정 버튼을 추가
- 설치 상태, 로컬 저장 안내, 데이터 JSON 백업·복원, 도움말에 실제로 접근 가능
- 백업 파일을 먼저 검증하고 컬렉션별 결과 개수를 보여준 뒤 `합치기` 또는 `전체 교체`를 선택
- 복원 중 일부 저장이 실패하면 작업 전 스냅샷으로 자동 rollback하고, Android는 Storage Access Framework 문서 선택기를 사용
- 하단 4개 핵심 기록 탭은 유지하고 설정·백업은 상단 버튼으로 분리

### AI·Bridge·음식 사진 기능 비활성화

- 홈의 AI 카드와 더보기의 앱 수정 행을 제거했으며, 이후 운동·식단 전체 기능도 제품 범위에서 제외
- `/ai`, `/ai/edit`, `/ai/settings`는 `/app`으로 이동하며 해당 지연 로딩 청크를 production bundle에 포함하지 않음
- APK의 Bridge HTTP/SSE transport, Android Keystore token store, network-status API와 이미지 chooser를 제거하고 JSON 백업 chooser만 유지
- `ACCESS_NETWORK_STATE`와 cleartext 예외를 제거해 Android cleartext traffic을 명시적으로 차단
- 보관된 과거 AI 모듈은 현행 앱에서 import하지 않으며 사용자 명시 요청 없이 다시 노출하지 않음

### 결제 앱 알림 일괄 가져오기

- 가계부 상단에서 결제 알림 가져오기를 명시적으로 켜고 삼성월렛·카카오페이·토스를 개별 선택한 뒤 Android 알림 접근 설정으로 이동
- 넓은 시스템 권한이라는 점과 사이드로드 앱의 제한된 설정 절차를 숨기지 않고 안내
- 선택한 결제 앱의 새 승인만 기기 내부 대기열에 모은 뒤 Orbit 실행·foreground 복귀 때 가계부에 일괄 반영
- 자동 반영 건은 사용처·금액·소스별 자동 출처를 구분해 표시하고 기존 삭제 동작으로 오인식을 정리 가능
- 원문, 카드·계좌번호, 잔액은 화면·저장소·네트워크에 남기지 않고, 취소·환불·입출금·송금·이체·충전·적립·광고는 대상에서 제외
- 카카오페이와 토스는 상호명이 확인될 때만 가져오며 앱 이름을 대체 상호로 저장하지 않음
- 자동 분류는 코레일·티머니를 `교통`, `커피` 포함 상호를 `커피`, 다이소와 나머지를 `기타`로 처리. 사용자가 추가한 분류·키워드는 빠른 입력·정기 결제·새 자동 가져오기와 기존 자동 가져오기 기록에 반영

### 가계부 내부 메뉴·월별 카테고리 내역과 기존 카카오페이 상호명 보정

- 월 지갑은 항상 보이고 긴 본문은 `내역`, `수동 입력`, `자동 기록`, `분류·공유` 4개 내부 메뉴로 분리
- 내역에는 월별 카테고리 지출과 최근 거래, 수동 입력에는 수입·지출 입력과 거래 수정, 자동 기록에는 정기 결제·결제 알림·이전 상호명 확인, 분류·공유에는 분류 규칙과 파일 전달을 배치
- 카테고리 카드를 누르면 현재 연월의 해당 지출만 거래 날짜와 함께 표시하며 `전체 내역`으로 필터를 해제
- 내부 메뉴는 52px 조작 영역, 현재 상태, 좌우 방향키 이동을 제공하고 350px 이하에서는 보조 설명만 접음
- native parser는 `상호명을~ 값`, 조사 포함 라벨, 라벨/값 분리 extras를 지원하고 짧은 일반 단어가 `사용처명`·`결제금액`보다 먼저 제거되던 순서를 수정
- Web은 새 카카오페이 후보를 다시 정제하고 기존 자동 기록의 라벨·결제 문구·`처명` 같은 이전 parser 조각을 앱 시작 시 보정
- 과거에 `카카오페이` 앱 이름만 저장된 거래는 원문을 추측하지 않고 날짜·금액을 보여준 뒤 사용자가 실제 상호명을 입력

### 버전형 로컬 백업과 Android SAF

- `formatVersion`이 있는 LifeHub JSON만 정규화하고, Bridge token·승인·대화·thread 상태는 백업에서 거부
- 같은 ID의 백업 항목이 우선하는 `merge`와 백업 내용만 남기는 `replace`를 복원 전 개수로 비교하고, 신체정보·브리핑 설정 변경도 별도 경고
- 모든 데이터를 먼저 검증하고 쓰기 실패 시 이전 스냅샷 전체를 되돌려 부분 복원을 피함
- 복원 확정 직전 최신 저장소를 다시 읽어 외부에서 추가된 기록을 merge가 누락하지 않게 함
- 웹과 Android 모두 strict UTF-8·JSON 객체와 8 MiB 단일 상한을 검증. Android 내보내기·가져오기는 `ACTION_CREATE_DOCUMENT`/`ACTION_OPEN_DOCUMENT`와 `application/json` MIME을 사용하는 SAF 흐름으로 분리
- 복원 미리보기에 live announcement와 포커스 이동을 연결하고 주요 버튼 44px, 보조 글자 AA 대비를 적용

## 2026-09-10 — 0.9.0-debug AI 첨부·모델·사용 한도

AI 채팅에 PDF/TXT/Markdown/CSV/JSON/LOG 첨부와 추출 내용 미리보기·삭제를 추가했다.
한 메시지 3개, 텍스트 파일 200KB/PDF 5MB, 파일당 추출 12,000자/합계 24,000자로 제한하며
PDF는 최대 30쪽의 텍스트만 읽는다. 스캔/OCR·암호 PDF는 지원하지 않는다. 일부 추출은 UI에 표시한다.
추출 내용은 대화 JSON/Markdown과 같은 폴더 검색 색인에 남고, 전송 시 AI에 제공된다.
원본 파일을 복제 보관하지 않으며 Android 파일 선택은 사용자가 고른 문서 URI만 허용한다.
PDF.js 워커·CMap·기본 글꼴과 라이선스를 APK에 포함하여 외부 CDN 없이 읽는다.

로그인한 Codex의 model/list 결과로 모델을 선택하고 실제 요청에 반영한다. 자동 모델은 기존 설정을 따른다.
account/rateLimits/read의 잔여율·초기화 시각·조회 시각을 표시한다. 정확한 잔여 토큰 수는 제공되지 않으므로
추정하지 않는다. 한도는 계정 기준이며 선택 모델의 별도 한도와 다를 수 있다.
화면 진입·답변 완료·수동 새로고침 때만 조회하고 주기적인 폴링은 하지 않는다.
기존 대화·인증을 유지하며, 첨부/모델을 지원하지 않는 구형 실행 환경은 전송 전에 안내한다.

검증: 웹/로컬 서버 회귀 테스트, 실제 PDF와 번들 글꼴 추출, 로그인된 Codex의 모델/한도 조회.
Android 파일 선택 및 업데이트 APK의 실제 화면·전송은 설치 후 기기 확인이 필요하다.
