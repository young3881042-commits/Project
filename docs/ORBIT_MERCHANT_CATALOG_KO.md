# Orbit 사용처 기본 분류 자료

확인일: 2026-09-17. 공식 브랜드/업체 사이트에서 업종을 확인한 **24개 브랜드, 61개 이름 표기**를 수록했다.

- 기계 판독 원본: `apps/web/src/features/finance/merchantCatalog.json`
- 표 형식 사본: [ORBIT_MERCHANT_CATALOG.csv](ORBIT_MERCHANT_CATALOG.csv)
- 앱에서는 가계부 → 분류 관리 → 기본 사용처 자료에서 출처 링크를 확인한다.

## 자료의 의미

실제 사용자의 결제 내역을 수집한 자료가 아니다. 브랜드 이름·공식 업종·출처 URL만 수집했으며 별칭은 이름 정규화/통상 표기 변형이다. 별칭이 실제 카드 명세서에 나타난다는 보장은 없다. 웹페이지 원문·이미지·가격표를 복제하지 않았다.

`category`는 공식 사이트가 지정한 금융 분류가 아니라 Orbit의 제안값이다. 커피전문점은 커피, 음식점·베이커리·아이스크림은 식비, 편의점·슈퍼·의류는 쇼핑, 철도는 교통으로 연결했다. 다이소는 기존 Orbit의 기타 기본값을 유지했다. 편의점에서 실제로 무엇을 샀는지는 알 수 없으므로 식비로 단정하지 않는다.

예를 들어 [메가MGC커피의 공식 메뉴·브랜드 소개](https://www.mega-mgccoffee.com/), [CU의 편의점·상품 안내](https://cu.bgfretail.com/), [GS리테일의 사업 소개](https://hpsimg.gsretail.com/gsretail/ko/intro/ceo-message), [코레일 승차권 사이트](https://www.korail.com/)로 업종을 확인했다. 나머지 업체의 직접 출처는 CSV와 JSON 각 행에 있다.

## 적용 순서와 범위

1. 같은 사용처에 사용자가 이미 적용한 분류.
2. 사용자가 직접 설정한 분류 키워드.
3. 이 기본 자료의 정확한 이름/지점명 일치.
4. 기존 일반 키워드와 필요 시 공개 사용처명으로 AI 검색.

새 알림 가져오기와 기존 알림 거래 중 기타인 항목에 적용한다. 이미 분류된 항목을 일괄 덮어쓰지 않는다. 별도 API 키/서버/계정이 필요 없으며 오프라인에서도 기본 이름 매칭이 작동한다.

CU/SRT 같은 짧은 이름은 다른 단어 안에서 부분 일치시키지 않는다. 결제대행사 이름만 있거나, 구분할 수 없는 이름·민감한 숫자가 있으면 기본 자료로 분류하지 않는다. PG 접두사 뒤에 명확한 브랜드가 있는 경우만 정해진 구분자를 제거한다.

## 다음 자료 보강

추가 업체는 공식 페이지와 확인일을 함께 등록하고, 같은 이름의 다른 업종·지점 접미사·사용자 분류 우선순위 테스트를 통과해야 한다. 구독·종합 쇼핑 플랫폼·병원/약국은 현재 5개 기본 분류만으로 세밀하게 나누기 어려워 이번 자료에서 임의로 확대하지 않았다.
